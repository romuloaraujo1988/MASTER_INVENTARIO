## 📊 Queries SQL Necessárias

### 1. Tempo Médio por Coleta
```sql
SELECT 
    AVG(EXTRACT(EPOCH FROM (c2.DATA_COLETA - c1.DATA_COLETA))) as tempo_medio_segundos
FROM TABELA_COLETA c1
JOIN TABELA_COLETA c2 ON c2.ID = c1.ID + 1
WHERE c1.ID_INVENTARIO = ?
AND c1.ID_COLETOR = c2.ID_COLETOR;
```

### 2. Ranking de Coletores
```sql
SELECT 
    u.NOME_COMPLETO,
    COUNT(*) as total_coletas,
    COUNT(*) / NULLIF(DATE_PART('day', MAX(c.DATA_COLETA) - MIN(c.DATA_COLETA)), 0) as coletas_por_dia
FROM TABELA_COLETA c
JOIN TABELA_USUARIO u ON c.ID_COLETOR = u.ID
WHERE c.ID_INVENTARIO = ?
GROUP BY u.ID, u.NOME_COMPLETO
ORDER BY total_coletas DESC
LIMIT 10;
```

### 3. Economia de Tempo
```sql
SELECT 
    COUNT(*) as total_coletas,
    COUNT(*) * 18 / 3600.0 as horas_digital,
    COUNT(*) * 180 / 3600.0 as horas_papel,
    (COUNT(*) * 180 / 3600.0) - (COUNT(*) * 18 / 3600.0) as horas_economizadas
FROM TABELA_COLETA
WHERE ID_INVENTARIO = ?;
```

### 4. Taxa de Divergência
```sql
SELECT 
    COUNT(*) as total_coletas,
    SUM(CASE WHEN DIVERGENCIA = true THEN 1 ELSE 0 END) as divergencias,
    (SUM(CASE WHEN DIVERGENCIA = true THEN 1 ELSE 0 END) * 100.0 / COUNT(*)) as taxa_divergencia
FROM TABELA_COLETA
WHERE ID_INVENTARIO = ?;
```
