========================================
  CORRECAO DE TIMESTAMPS SQLITE
  Sistema de Inventario v2.0.0
========================================

PROBLEMA:
---------
Erro ao carregar salas no modo offline:
"Timestamp format must be yyyy-mm-dd hh:mm:ss[.fffffffff]"

CAUSA:
------
SQLite armazena timestamps como TEXT, mas Java espera formato específico.

SOLUCAO:
--------
✅ Script SQL que corrige estrutura e dados
✅ Triggers para manter formato correto
✅ Backup automático antes de executar
✅ Validação de resultado

ARQUIVOS CRIADOS:
-----------------
1. sql/fix_sqlite_timestamp_compatibility.sql
   - Script de correção completo
   - Recria tabelas com formato correto
   - Adiciona triggers de proteção

2. fix-sqlite-timestamps.bat
   - Execução automatizada
   - Backup automático
   - Validação de resultado

3. CORRECAO_TIMESTAMP_SQLITE.md
   - Documentação completa
   - Exemplos de uso
   - Troubleshooting

COMO USAR:
----------
1. Execute: fix-sqlite-timestamps.bat
2. Aguarde conclusão
3. Verifique mensagem de sucesso

OU MANUALMENTE:
---------------
sqlite3 data\inventario_offline.db < sql\fix_sqlite_timestamp_compatibility.sql

FORMATO CORRETO:
----------------
ANTES: 2024-11-21T14:30:00Z (ISO 8601)
DEPOIS: 2024-11-21 14:30:00 (Java compatible)

-------------------
✅ SALA_INVENTARIO (DATA_INICIO, DATA_FIM)
✅ COLETA (DATA_COLETA)
✅ SALA (DATA_CADASTRO)
✅ TABELA_INVENTARIO (DATA_INICIO, DATA_FIM, DATA_CRIACAO)
