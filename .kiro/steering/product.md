# Product Overview

## SIHCP - Sistema de Histórico e Coleta Patrimonial

Asset management system developed for Instituto Federal de Mato Grosso (IFMT) to control and track institutional assets through inventory collection and specialized reporting.

## Core Purpose

Comprehensive asset management solution that enables:
- Complete control over institutional assets
- Efficient inventory processes with QR code scanning
- Integration with SUAP (institutional system)
- Real-time reporting and analytics
- Mobile data collection via Android app

## Key Components

### Desktop Application (Java Swing)
Main system interface for administrators and operators to manage users, assets, inventory processes, and generate reports.

### Mobile API (Spring Boot)
REST API backend that serves the Android mobile app, providing authentication, data synchronization, and collection endpoints.

### Android Mobile App (Kotlin)
Native Android application for field inventory collection with QR code scanning, offline mode, and real-time synchronization.

## Target Users

- **Administrators**: Full system access and configuration
- **Managers**: Reports and oversight
- **Operators**: Daily operations and data collection
- **Auditors**: Audit trails and compliance reports
- **Field Collectors**: Mobile app users for physical inventory

## Business Value

- Automates manual inventory processes
- Eliminates human errors in asset tracking
- Provides complete traceability of all assets
- Ensures compliance with Brazilian public sector regulations
- Optimizes resource allocation and reduces operational costs
