# ColetaFrame_v2 - Guia Rápido

## 🚀 Início Rápido

### Coleta Normal (Itens com Etiqueta)

1. **Selecione a sala** no combo superior
2. **Digite ou escaneie** o número do patrimônio
3. **Verifique** as informações exibidas
4. **Pressione F4** ou clique em "Registrar Item"
5. **Repita** para o próximo item

### Itens Sem Patrimônio

1. **Selecione a sala** na aba "Coleta Normal"
2. **Vá para** aba "Itens Sem Patrimônio"
3. **Pesquise** descrição existente OU digite nova
4. **Selecione** a categoria
5. **Clique** em "Registrar"
6. **Repita** para o próximo item

---

## ⌨️ Atalhos

| Tecla | Ação |
|-------|------|
| **F4** | Registrar item (Coleta Normal) |
| **Enter** | Buscar patrimônio / Pesquisar descrição |
| **Tab** | Navegar entre campos |

---

## 🎯 Dicas Rápidas

### ✅ Faça
- Selecione a sala ANTES de começar
- Use o leitor de código de barras para agilizar
- Verifique o histórico para confirmar registro
- Adicione observações quando necessário

### ❌ Evite
- Trocar de sala sem finalizar a anterior
- Registrar sem verificar as informações
- Deixar campos obrigatórios vazios

---

## 🔍 Campos Obrigatórios

### Coleta Normal
- ✅ Sala selecionada
- ✅ Patrimônio encontrado

### Itens Sem Patrimônio
- ✅ Sala selecionada (na aba Coleta Normal)
- ✅ Descrição do item
- ✅ Categoria

---

## 🎨 Cores de Status

| Cor | Significado |
|-----|-------------|
| 🟢 Verde | Sucesso / Registrado |
| 🔵 Azul | Informação / Normal |
| 🟡 Amarelo | Aviso / Atenção |
| 🔴 Vermelho | Erro / Ação destrutiva |

---

## 📊 Tabelas

### Histórico de Coleta
- **Data/Hora**: Quando foi coletado
- **Patrimônio**: Número ou "SEM ETIQUETA"
- **Descrição**: Nome do item
- **Estado**: Condição atual

### Itens Sem Patrimônio
- **Data/Hora**: Quando foi registrado
- **Descrição**: Nome do item
- **Categoria**: Tipo do item
- **Localização**: Onde foi encontrado

## ⚠️ Problemas Comuns

### "Localização não definida"
➡️ Selecione uma sala na aba "Coleta Normal"

### "Acesso Negado"
➡️ Verifique se você é participante do inventário

### "Patrimônio já coletado"
➡️ Item já foi registrado neste inventário

### Botão desabilitado
➡️ Verifique campos obrigatórios
