## 🚀 Novidades da Versão 1.2

Agora você pode sair do aplicativo de forma segura através do menu.

### ✅ Melhorias na Coleta via QR Code
Interface aprimorada com feedback visual e melhor fluxo de uso.

## 📱 Como Usar o Logoff

### Passo a Passo:

1. **Abra o aplicativo** e faça login normalmente

2. **No Dashboard**, localize o menu no canto superior direito (ícone ⋮)

3. **Clique no menu** e selecione **"Sair"**

4. **Confirme** clicando em **"Sim, sair"** no diálogo

5. **Pronto!** Você será redirecionado para a tela de login

### 🔒 Segurança

- Todos os dados de sessão são limpos
- Token de autenticação é removido
- Dados do usuário são apagados da memória
- Necessário fazer login novamente para usar o app

## 📷 Como Fazer Coleta via QR Code

### Método 1: Scan Rápido (Recomendado)

1. **No Dashboard**, clique no botão **"Scan Rápido"**

2. **Selecione a sala** onde está fazendo o inventário

3. **Clique em "Escanear QR Code"**

4. **Posicione o QR Code** dentro do quadro da câmera

5. **Aguarde** o sistema processar o código

6. **Preencha** os campos:
   - ✅ Localização (obrigatório)
   - Observações (opcional)

7. **Clique em "Salvar"**

8. **Pronto!** Coleta registrada com sucesso

### Método 2: Coleta Manual

1. **No Dashboard**, clique no botão **"Coleta Manual"**

2. **Selecione a sala**

3. **Digite manualmente** o código do patrimônio

4. **Preencha** os demais campos

5. **Clique em "Salvar"**

## 💡 Dicas de Uso

### Para Melhor Experiência com QR Code:

✅ **Iluminação adequada** - Evite locais muito escuros ou com reflexo

✅ **Distância correta** - Mantenha o celular a 10-20cm do QR Code

✅ **Câmera limpa** - Limpe a lente da câmera antes de usar

✅ **QR Code legível** - Certifique-se que o código não está danificado

✅ **Estabilidade** - Mantenha o celular firme ao escanear

### Para Coleta Eficiente:

✅ **Selecione a sala primeiro** - Isso agiliza o processo

✅ **Preencha observações** - Ajuda na identificação posterior

✅ **Verifique os dados** - Confirme se o patrimônio está correto

✅ **Sincronize regularmente** - Evite perda de dados

## ⚠️ Solução de Problemas

### QR Code não é reconhecido

**Problema:** Scanner não lê o QR Code

**Soluções:**
- Verifique a iluminação do ambiente
- Limpe a câmera do celular
- Aproxime ou afaste o celular do código
- Verifique se o QR Code não está danificado
- Tente usar a coleta manual

### Erro ao salvar coleta

**Problema:** Mensagem de erro ao salvar

**Soluções:**
- Verifique se preencheu a localização (obrigatório)
- Certifique-se que escaneou um patrimônio
- Verifique sua conexão com a internet
- Tente novamente em alguns segundos

### Logoff não funciona

**Problema:** Não consegue sair do aplicativo

**Soluções:**
- Feche e abra o aplicativo novamente
- Limpe o cache do aplicativo
- Reinstale o aplicativo se necessário

### Câmera não abre

**Problema:** Scanner não abre a câmera

**Soluções:**
- Verifique as permissões do aplicativo
- Vá em Configurações > Apps > Inventário > Permissões
- Ative a permissão de câmera
- Reinicie o aplicativo
