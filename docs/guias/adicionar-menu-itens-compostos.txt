PASSO 2: Adicionar método para abrir o frame
---------------------------------------------

Localizar no MainFrame.java o método:

    private void abrirPatrimonio() {
        ...
    }

Adicionar LOGO APÓS:

    /**
     * Abre a tela de gestão de itens compostos
     */
    private void abrirItensCompostos() {
        try {
            ItemCompostoFrame frame = new ItemCompostoFrame(usuarioLogado);
            frame.setVisible(true);
        } catch (Exception e) {
            ModernDialog.showMessage(this,
                "Erro ao abrir gestão de itens compostos: " + e.getMessage(),
                "Erro", JOptionPane.ERROR_MESSAGE);
            e.printStackTrace();
        }
    }


PASSO 3: (OPCIONAL) Adicionar botão no dashboard

PASSO 4: Compilar e testar
---------------------------

1. Salvar MainFrame.java
2. Compilar o projeto:
   mvn clean compile

3. Executar:
   mvn exec:java -Dexec.mainClass="com.inventario.SistemaInventarioApplication"

4. Fazer login
5. Ir em Menu → Inventário → Gerenciar Itens Compostos

TROUBLESHOOTING
---------------

Erro: "Cannot find symbol ItemCompostoFrame"
Solução: Verificar se os arquivos foram criados em src/main/java/com/inventario/view/

Erro: "usuarioLogado cannot be resolved"
Solução: Verificar se o método está dentro da classe MainFrame

Erro de compilação
Solução: Executar mvn clean compile -X para ver detalhes
