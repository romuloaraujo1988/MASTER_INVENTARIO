┌──────────────────────────────────────────────────────────────────────────────┐
│  PASSO 1: DESINSTALAR APP ANTIGO                                            │
└──────────────────────────────────────────────────────────────────────────────┘

    📱 No smartphone:
    
    Configurações → Aplicativos → SIHCP Mobile → Desinstalar
    
    ✓ Confirme a desinstalação


┌──────────────────────────────────────────────────────────────────────────────┐
│  PASSO 2: INSTALAR NOVO APK                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────────┐
    │  OPÇÃO A: INSTALAÇÃO AUTOMÁTICA (USB)                                  │
    └─────────────────────────────────────────────────────────────────────────┘
    
    1. Conecte o smartphone ao computador via USB
    
    2. No computador, clique duas vezes em:
       
       📄 instalar-app-debug.bat
    
    3. Aguarde a mensagem de sucesso
    
    
    ┌─────────────────────────────────────────────────────────────────────────┐
    │  OPÇÃO B: INSTALAÇÃO MANUAL                                             │
    └─────────────────────────────────────────────────────────────────────────┘
    
    1. Copie o arquivo para o smartphone:
       
       📦 SIHCP-Mobile-Debug.apk (9.8 MB)
    
    2. No smartphone, abra o arquivo APK
    
    3. Permita instalação de fontes desconhecidas (se solicitado)
    
    4. Toque em "Instalar"


┌──────────────────────────────────────────────────────────────────────────────┐
│  PASSO 3: PRIMEIRO ACESSO                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

    1. Abra o app SIHCP Mobile
    
    2. Faça login com suas credenciais:
       
       👤 Usuário: _____________
       🔒 Senha:   _____________
    
    3. Aguarde o carregamento do dashboard


┌──────────────────────────────────────────────────────────────────────────────┐
│  PASSO 4: TESTAR SCANNER QR CODE                                            │
└──────────────────────────────────────────────────────────────────────────────┘

    1. No dashboard, toque em:
       
       📷 Coleta Rápida (QR Code)
    
    2. Selecione uma sala da lista
    
    3. ⚠️  IMPORTANTE: Quando solicitado, toque em:
       
       ✓ PERMITIR (permissão de câmera)
    
    4. A câmera deve abrir automaticamente
    
    5. Posicione um QR Code de patrimônio na área de captura
    
    6. O sistema deve:
       ✓ Ler o QR Code
       ✓ Buscar o patrimônio
       ✓ Exibir informações
       ✓ Permitir coletar


┌──────────────────────────────────────────────────────────────────────────────┐
│  VERIFICAÇÃO DE PERMISSÕES                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

    Se a câmera não abrir:
    
    📱 Configurações → Aplicativos → SIHCP Mobile → Permissões
    
    Certifique-se que está PERMITIDO:
    
    ✓ Câmera
    ✓ Armazenamento (se necessário)

┌──────────────────────────────────────────────────────────────────────────────┐
│  TROUBLESHOOTING RÁPIDO                                                      │
└──────────────────────────────────────────────────────────────────────────────┘

    ❌ Scanner não abre
       → Verificar permissão de câmera
       → Reiniciar aplicativo
    
    ❌ Câmera não funciona
       → Fechar outros apps que usam câmera
       → Reiniciar smartphone
    
    ❌ QR Code não é lido
       → Melhorar iluminação
       → Limpar lente da câmera
       → Aproximar/afastar câmera
    
    ❌ Patrimônio não encontrado
       → Verificar se QR Code é válido
       → Sincronizar dados
       → Verificar conexão com servidor
    
    ❌ App trava
       → Limpar cache do app
       → Desinstalar e reinstalar
