================================================================================
  CHECKLIST DE PROBLEMAS DE REDE
================================================================================

[ ] 1. MESMA REDE WIFI
   - Computador e celular devem estar na MESMA rede WiFi
   - Não use dados móveis no celular
   - Verifique o nome da rede WiFi em ambos

[ ] 2. VPN DESATIVADA
   - Desative VPN no celular
   - Desative VPN no computador

[ ] 3. MODO AVIAO
   - Certifique-se que modo avião está DESLIGADO
   - WiFi deve estar LIGADO

[ ] 4. ISOLAMENTO DE AP (Roteador)
   - Alguns roteadores bloqueiam comunicação entre dispositivos
   - Verifique configurações do roteador
   - Procure por "AP Isolation" ou "Client Isolation"
   - Deve estar DESABILITADO

[ ] 5. FIREWALL DO ROTEADOR
   - Alguns roteadores têm firewall próprio
   - Verifique se porta 8081 está liberada

================================================================================
  COMANDOS PARA VERIFICAR NO COMPUTADOR
================================================================================

Abra o PowerShell ou CMD e execute:

1. Ver IP do computador:
   ipconfig | findstr "IPv4"

2. Verificar se servidor está rodando:
   netstat -ano | findstr :8081

3. Testar servidor localmente:
   curl http://localhost:8081/inventario/api/mobile/health

4. Liberar firewall (se necessário):
   netsh advfirewall firewall add rule name="Inventario" dir=in action=allow protocol=TCP localport=8081
