┌─────────────────────────────────────────────────────────────────────────────┐
│ FLUXO ATUAL (SEM OTIMIZAÇÃO)                                                │
└─────────────────────────────────────────────────────────────────────────────┘

    User Input
        ↓
    [Debounce 300ms]
        ↓
    QuickSearchViewModel
        ↓
    BuscarPatrimoniosUseCase
        ↓
    ┌─────────────────────────────────────────┐
    │ Tentar Servidor (PatrimonioApi)         │ ← 400-500ms
    │ SELECT * FROM patrimonio                │
    │ WHERE numero LIKE '%query%'             │
    │    OR descricao LIKE '%query%'          │
    │    OR sala LIKE '%query%'               │
    │ LIMIT 100                               │
    └─────────────────────────────────────────┘
        ↓ (se falhar)
    ┌─────────────────────────────────────────┐
    │ Fallback Local (PatrimonioDao)          │ ← 400-500ms
    │ (mesma query no SQLite)                 │
    └─────────────────────────────────────────┘
        ↓
    Mostrar Resultados (100 patrimônios)
        ↓
    User vê resultado após 400-500ms


┌─────────────────────────────────────────────────────────────────────────────┐
│ FLUXO OTIMIZADO (COM ÍNDICES + CACHE)                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    User Input
        ↓
    [Debounce 300ms]
        ↓
    QuickSearchViewModel
        ↓
    BuscarPatrimoniosUseCase
        ↓
    ┌─────────────────────────────────────────┐
    │ Verificar Cache (SearchCache)           │ ← 1-5ms (cache hit!)
    │ Chave: "query:filtro"                   │
    │ Se encontrado → Retornar imediatamente  │
    └─────────────────────────────────────────┘
        ↓ (se não estiver em cache)
    ┌─────────────────────────────────────────┐
    │ Tentar Servidor (PatrimonioApi)         │ ← 100-200ms (com índices)
    │ SELECT * FROM patrimonio                │
    │ WHERE numero LIKE '%query%'             │
    │    OR descricao LIKE '%query%'          │
    │    OR sala LIKE '%query%'               │
    │ LIMIT 100                               │
    │                                         │
    │ ✓ Usa índices:                          │
    │   - idx_patrimonio_numero               │
    │   - idx_patrimonio_descricao            │
    │   - idx_patrimonio_sala                 │
    └─────────────────────────────────────────┘
        ↓ (se falhar)
    ┌─────────────────────────────────────────┐
    │ Fallback Local (PatrimonioDao)          │ ← 50-100ms (com índices)
    │ (mesma query no SQLite com índices)     │
    └─────────────────────────────────────────┘
        ↓
    ┌─────────────────────────────────────────┐
    │ Cachear Resultado                       │ ← 1ms
    │ searchCache.put("query:filtro", result) │
    └─────────────────────────────────────────┘
        ↓
    Mostrar Resultados (100 patrimônios)
        ↓
    User vê resultado após 50-200ms (primeira busca)
                        ou 1-5ms (buscas subsequentes)

┌─────────────────────────────────────────────────────────────────────────────┐
│ ARQUITETURA DO CACHE (SearchCache.kt)                                        │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────┐
    │                    SearchCache (LRU)                        │
    │                                                             │
    │  Tamanho máximo: 50 entradas                               │
    │  Expiração: 30 minutos                                     │
    │  Ordem: Least Recently Used (LRU)                          │
    │                                                             │
    │  ┌─────────────────────────────────────────────────────┐   │
    │  │ Entrada 1: "patrimonio:ALL"                         │   │
    │  │ └─ 45 resultados (2 min atrás)                      │   │
    │  │                                                     │   │
    │  │ Entrada 2: "cadeira:COLETADOS"                      │   │
    │  │ └─ 12 resultados (5 min atrás)                      │   │
    │  │                                                     │   │
    │  │ Entrada 3: "mesa:PENDENTES"                         │   │
    │  │ └─ 8 resultados (10 min atrás)                      │   │
    │  │                                                     │   │
    │  │ ... (até 50 entradas)                               │   │
    │  │                                                     │   │
    │  │ Entrada 50: "computador:DIVERGENCIAS"               │   │
    │  │ └─ 3 resultados (25 min atrás)                      │   │
    │  └─────────────────────────────────────────────────────┘   │
    │                                                             │
    │  Métodos:                                                   │
    │  • get(key) → Retorna resultado ou null                    │
    │  • put(key, value) → Armazena resultado                    │
    │  • clear() → Limpa todo o cache                            │
    │  • cleanExpired() → Remove entradas expiradas              │
    │  • getStats() → Retorna estatísticas                       │
    └─────────────────────────────────────────────────────────────┘
